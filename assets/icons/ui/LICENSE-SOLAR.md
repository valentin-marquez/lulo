# Solar icons

The SVG files in this folder are icons from the Solar icon set by 480 Design
(https://www.figma.com/community/file/1166831539721848736), taken from the
`@iconify-json/solar` package. They are renamed after the Lucide icon paths
they replace and otherwise unchanged, except `ellipsis-vertical.svg`, which is
Solar's `menu-dots` turned a quarter turn.
